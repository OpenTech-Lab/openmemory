# Release v0.1.13

- Date: 2026-08-06
- Server version: 0.1.13
- Web version: 0.1.13

## Changes

- feat: AI-generated AWS architecture diagrams on the Design tab. A new
  `ai.design_diagram` MCP endpoint (`apps/server/src/design_ai.rs`, same
  suggestion-only shape as `ai.autofill`) turns a free-text prompt (e.g. "a
  serverless API with S3 storage and a Postgres RDS backend") into a mermaid
  `architecture-beta` diagram, drawing icons from a curated 67-name AWS/Amazon
  subset of `@iconify-json/logos` (`apps/web/lib/aws-icon-pack.json`,
  generated once via `scripts/gen-aws-icon-pack.mjs` and registered client-side
  with `mermaid.registerIconPacks`). The system prompt mandates
  double-quoted `[...]` titles (an unquoted title containing a hyphen,
  paren, or slash is a parser error) and caps diagram size (≤14 services,
  ≤2 groups) to stay within the shared `llm.rs` token budget; a server-side
  `sanitize_source` pass additionally rewrites any icon name outside the
  allowlist to a generic `logos:aws` fallback so a hallucinated icon can
  never render as a broken reference. A new "AWS" kind (amber badge, new
  "Infrastructure" group in the Kind selector) ships with its own starter
  template. The New/Edit Diagram dialog gains an "AI prompt" field +
  "Generate with AI" button (same loading/toast pattern as the existing
  Resources/Projects "Suggest with AI" buttons) that fills the in-memory
  mermaid source and live preview — nothing is written to the database until
  the dialog's own Create/Save button is clicked.
- feat: zoom / fit-to-width controls on rendered mermaid diagrams
  (`apps/web/components/mermaid-diagram.tsx`), replacing bare
  `overflow-x: auto` scrolling for diagrams too wide for their container. A
  small control row (zoom in/out, fit-to-width, reset) sits above the
  diagram; zoom is a CSS `transform: scale()` on the rendered SVG's
  container, computed from the SVG's `viewBox` width rather than any new
  pan-zoom dependency. Diagrams wider than their container auto-fit on
  first render instead of requiring a manual click, and zoom state resets
  whenever the diagram source changes so a stale scale never carries over
  to the next diagram. Applies to every existing diagram kind (ui,
  structure, workflow, schema, sequence, deployment, characters, plot,
  timeline, world, factions) as well as the new AWS kind, since they all
  share this one component.
