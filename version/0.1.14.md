# Release v0.1.14

- Date: 2026-08-06
- Server version: 0.1.14
- Web version: 0.1.14

## Changes

- feat: interactive React Flow diagram editor for the Design tab, alongside
  the existing mermaid text format. A new `diagram_type` column on
  `project_designs` (`mermaid` | `reactflow`, defaulting to `mermaid` so
  every existing design keeps rendering exactly as before) is set at
  creation and locked thereafter — a design's format doesn't change after
  the fact in v1. For `reactflow` designs, `source` stores React Flow's own
  `{ nodes, edges, viewport }` shape (`apps/web/lib/design-graph.ts`), with
  a custom `design` node type (`apps/web/components/design-node.tsx`) that
  renders an inline AWS icon (via `apps/web/lib/aws-icons.ts`, drawing from
  the same icon pack the mermaid AWS kind already uses) or a kind-based
  lucide fallback. The new `apps/web/components/design-canvas.tsx` editor
  (structurally following `workflows-panel.tsx`'s proven React Flow setup)
  adds a draggable AWS-icon palette, a node inspector for label/icon/note,
  free-form branching/merging connections (unlike the workflow canvas's
  single-chain constraint), an Auto-arrange button
  (`apps/web/lib/design-layout.ts`, dagre left-to-right layout), and an
  Export PNG button (`apps/web/lib/design-export.ts`, captures the full
  `.react-flow__viewport` including nodes scrolled off-screen).
  `project-design-panel.tsx` gains a Mermaid/React Flow format toggle on the
  New Diagram dialog only, branches its preview and edit dialog on
  `diagram_type`, and widens the dialog substantially for the canvas case.
  The existing `ai.design_diagram` MCP endpoint gained a `format` field —
  `format: "reactflow"` routes to a new `design_ai::generate_graph`
  (structured node/edge JSON instead of mermaid text, sanitized the same
  way: unknown icons fall back, dangling edges and blank-label nodes are
  dropped, node count is capped) and the AI's output is run through the
  same dagre auto-layout before reaching the canvas, since the LLM omits
  positions entirely.
- No changes to mermaid rendering, the MCP stdio server (graph generation
  is web-UI only for now), or any other Design tab behavior for existing
  mermaid designs.
