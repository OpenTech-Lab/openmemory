# Release v0.1.9

- Date: 2026-08-06
- Server version: 0.1.9
- Web version: 0.1.9

## Changes

- feat: add AI autofill — a suggestion-only `ai.autofill` endpoint that proposes
  summary/tags/importance (memory), description/labels/priority (task), and
  description/tags (resource) from raw content, with a "Suggest with AI"
  button on the memory, resource, and task create dialogs. Tags remain
  free-form text; existing top tags are passed to the LLM only as a soft
  preference hint, never a hard constraint. Suggestions never overwrite a
  field the user already edited by hand, and a failed/unconfigured LLM never
  blocks the underlying create.
- refactor: generalize `llm.rs`'s provider call functions to take an explicit
  system prompt, user message, and timeout, so autofill (10s, interactive) and
  graph extraction (30s, background) share the same OpenRouter/Anthropic/
  OpenAI transport code without behavior changes to graph extraction.
- feat(cli): `mem save`/`mem resource-add` gain an `--auto` flag, and a new
  `mem autofill <memory|task|resource> <content>` subcommand for inspecting a
  suggestion without saving. `mem save`/`resource-add` now track which flags
  were explicitly passed so `--auto` only fills what the caller omitted —
  omitted fields still fall back to the server's existing defaults
  (importance 0.5, tags []).
