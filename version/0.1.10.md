# Release v0.1.10

- Date: 2026-08-06
- Server version: 0.1.10
- Web version: 0.1.10

## Changes

- feat: per-agent Usage Trend chart — a new `GET /agents/:id/stats/timeseries`
  endpoint buckets an agent's sessions/messages by day or week (zero-filled
  via `generate_series`), and the agent detail page renders it as a
  recharts area/line chart with a client-side OLS trend line projecting the
  next few buckets, a reference line marking where actual data ends, and a
  plain-language projection sentence beneath the chart. `bucket` is sanitized
  to the literal `day`/`week` in Rust before it ever reaches the
  `date_trunc`/interval SQL — never interpolated from the raw query param.
